# G0oD Auto Meets

Помощник для онлайн-лекций и рабочих встреч. Агент подключается по расписанию, запускает запись речи и отбор кадров, а после встречи готовит материал для чтения: от коротких тезисов до подробного пересказа со слайдами.

**Статус: проектирование.** Этот README описывает планируемые возможности. Рабочая реализация и команды запуска пока отсутствуют.

## Как это работает

Проект рассчитан на агента вроде Codex или Claude Code с доступом к браузеру, терминалу и встроенным пробуждениям по расписанию. Инструкции в `AGENTS.md` задают ему роль помощника по встречам.

1. Пользователь добавляет репозиторий как проект и просит агента выполнить настройку. Агент уточняет недостающие сведения, устанавливает зависимости и проверяет запись и распознавание на компьютере пользователя.
2. Агент получает расписание, находит ближайшую подходящую встречу и назначает пробуждение перед её началом.
3. Подключается через интерфейс площадки и одной командой запускает захват звука, распознавание речи и отбор кадров.
4. Периодически проверяет состояние встречи, например каждые 5–10 минут. Локальная запись продолжается между пробуждениями агента.
5. После окончания встречи завершает обработку и готовит отчёт.

## Что получает пользователь

- **Лекция:** краткие тезисы для быстрого ознакомления или развёрнутый текст со слайдами. После основного материала — отдельный блок с заданиями, сроками и организационными указаниями преподавателя.
- **Рабочая встреча:** подробный пересказ обсуждения, решения, договорённости и поручения.
- **Материалы встречи:** HTML-отчёт, транскрипция с временными отметками, отобранные изображения и исходное аудио для повторной обработки.

Кадры отбираются по изменениям изображения, повторяющиеся снимки отбрасываются. Количество слайдов не ограничивается заранее. В отчёте отмечаются неразборчивые фрагменты речи.

## Настройки

Для разных встреч используются отдельные файлы профилей: например, один для учёбы, другой для работы. Каждый содержит источник расписания, правила отбора событий, тип и подробность отчёта, а также дополнительные пожелания обычным текстом. Один календарь можно использовать в нескольких профилях с разными фильтрами.

Можно настроить язык и модель распознавания, интервалы обработки аудио, проверки кадров и пробуждений агента, область захвата и запись микрофона. Для рабочих встреч микрофон нужен, если в отчёт должны попасть собственные реплики пользователя.

## Требования и ограничения

- Первая версия рассчитана на **Windows 11**. macOS и Linux — возможные следующие этапы.
- Запись должна работать в фоне, пока пользователь занимается другими делами на том же компьютере. Для встречи используется отдельный экземпляр браузера, чтобы отделить её звук от других вкладок и приложений.
- Во время записи компьютер должен оставаться включённым и не переходить в сон. Захват при свёрнутом окне или заблокированном экране пока не гарантируется.
- Захват окна и звука не требует API конкретной площадки и рассчитан в том числе на BBB. Авторизация, допуск на встречу и особенности интерфейса могут потребовать участия пользователя; совместимость с конкретной площадкой проверяется при настройке.
- Скорость и точность распознавания зависят от оборудования, модели и качества звука. Если обработка отстаёт, аудио сохраняется для последующего распознавания. Имена, числа и сроки могут требовать проверки.
- Распознавание речи выполняется локально. При подготовке отчёта текст и изображения могут передаваться сервису используемого агента.

## Технологии

**Python** связывает готовые команды; **GStreamer** захватывает окно и звук приложения; **[whisper.cpp](https://github.com/ggml-org/whisper.cpp)** распознаёт речь; HTML-шаблоны задают оформление отчётов. Планируются варианты исполнения на NVIDIA через CUDA, на совместимых AMD/Intel через Vulkan и на CPU. Подходящий вариант выбирается после проверки оборудования. Отбор кадров выполняется обычным сравнением изображений.
