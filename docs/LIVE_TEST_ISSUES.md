Изолированные проверки после первой попытки: контролируемое окно Windows, перекрытое другим окном, дало три кадра нужного содержания (красный → зелёный → красный), а WAV длиной 24–65 с содержал тон целевого процесса 440 Гц без заметного тона второго процесса 880 Гц. Неверная пара PID/HWND отклоняется. Локальная красная HTML-страница в отдельном Edge заняла 92,9% кадра по проверке цвета. `doctor` прошёл 17 проверок; GStreamer-интеграция и весь набор тестов после исправлений — 40 passed. ASR отдельно распознал нейтральный синтезированный WAV, записал два чанка и метки времени; кэш и путь ошибки с отсутствующим executable отработали. Команда `import-wav` для того же нейтрального WAV завершилась `ready_for_summary`, дала два сегмента речи и создала HTML; ручной `summary.json` с настоящими ID источников успешно прошёл `render`. Синтетический `demo` также создал локальный HTML с аудио, кадрами и ссылками на источники.

Позднее короткий публичный ролик MinutePhysics был открыт в отдельном управляемом профиле Edge. Полная запись `data/browser-record-20260924/20260924T120416Z-121f5aff` завершилась `ready_for_summary`: 149,25 с WAV, 3 чанка Whisper, 27 выбранных кадров и HTML. Первый кадр и содержимое последующих кадров относились к нужному ролику; начало и конец его речи есть в транскрипции. Запись содержит также паузу до воспроизведения и рекламу после ролика. Отдельная сессия с неверным PID обёртки показала почти пустой WAV при статусе `ready_for_summary`. Реальное подключение к университетской конференции и полный агентный цикл календарь → вход → отчёт этим тестом не проверялись.
