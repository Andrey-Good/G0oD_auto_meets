# Проверка и приёмка

## Автоматические проверки

```text
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ruff check .
python -m pip wheel --no-deps -w dist .
python -m auto_meets demo
```

Unit-тесты работают без Windows, GStreamer, реальной модели, сети и пользовательских встреч. Они проверяют профили, пути, WAV и последний неполный блок, вызов ASR/тайм-ауты/кэш, повторную обработку, дедупликацию кадров и времена возврата, блокировки, защиту от повторного PID, экранирование HTML, ссылки на источники и устаревший пересказ. Ответы whisper.cpp в этих тестах подменены; это не проверка качества модели.

`test_capture_integration.py` дополнительно запускает **настоящий GStreamer**, когда `gst-launch-1.0` доступен в PATH или задан в `AUTO_MEETS_GST`. Он использует только `backend="test"` (искусственные звук и картинка), проверяет отдельный процесс, остановку, event_key, WAV, кадры и честный `needs_retry` при выключенном ASR. Без GStreamer тест помечается как пропущенный. Нельзя описывать такой skip как проверенный захват.

CI запускает независимые тесты на Windows и Linux с Python 3.11/3.13. У hosted Windows runner нет настоящей лекции, пользовательской авторизации и нужного звукового окружения: он не заменяет следующие шаги.

## Приёмка на Windows-компьютере пользователя

Делай тесты на собственных/разрешённых материалах. Для первого запуска открой отдельный браузер и короткую тестовую запись, не настоящую лекцию, которую нельзя повторить.

| Проверка | Действие | Условие успеха |
|---|---|---|
| Инструменты | `doctor`, затем `whisper-cli --help` | Все обязательные проверки успешны; путь/модель реально существуют. |
| Изоляция аудио | В браузере встречи воспроизведи речь A; в личном браузере/плеере — отличимую речь B | В WAV слышна A и **не слышна B**. Обязательно прослушать, не судить по размеру файла. |
| Тишина и часы | Речь, пауза 10 секунд, снова речь | Пауза сохранена; метки текста не сдвинуты на её длительность. |
| Кадры | Покажи слайд A, затем B, затем снова A | Два уникальных кадра; у A сохранено второе время. |
| Область | Выбери область презентации, убери чат/список участников | Сохранено именно выбранное содержимое, текст читается. |
| Фоновая работа | Перекрой окно другим приложением, не сворачивая; продолжи обычную работу | WAV и кадры продолжаются; другие приложения в них не попадают. |
| Независимость от агента | Заверши текущий вызов/закрой запускавший терминал; проверь из нового терминала/следующего пробуждения | `worker_alive=true`, длительность растёт. Если среда убивает дочерние процессы, авторабота в ней не подтверждена. |
| Микрофон | Только с разрешения включи `microphone=true`; произнеси фразу | Собственный голос записан, нет сильного эха/перегруза; с `false` не добавляется. |
| Реальная ASR | Запиши 2–3 минуты с именем, числом и датой, дождись обработки | Проверены текст, абсолютные метки, длительность обработки и GPU/CPU-сборка. Ошибки явно отмечены/исправлены по аудио. |
| Остановка | `stop`, затем `status` до завершения | GStreamer завершён, WAV читается целиком, последний короткий блок присутствует, ASR не остаётся висеть. |
| Повторный запуск | Во время теста повтори `start` с тем же event_key | Возвращена та же папка; второй захват не появился. |
| Авария | На тестовой записи завершить **только её worker**, затем `stop` и `process` | Осиротевшие дочерние процессы остановлены; сохранённое аудио восстановлено. Потерянное после сбоя время не выдаётся за записанное. |
| Ошибка ASR | В тестовом профиле указать отсутствующую модель, записать звук; затем исправить профиль и выполнить `process` | Исходник сохранён; ошибка видна; повторная обработка даёт материал. |
| Приватность и блокировка | Отдельно проверить блокировку/сворачивание, если они нужны пользователю | Зафиксировать наблюдаемое поведение; не обещать поддержку по результату обычного оконного теста. |
| Конкретная площадка | После базовых тестов короткая разрешённая встреча BBB/другой системы | Проверены вход, допуск, звук, презентация, окончание и повторное пробуждение агента. |
| HTML | Подготовить настоящий summary.json, `render`, открыть | Кадры читаются, время переводит аудио, задания/сроки не выдуманы, нет ложной полноты. |

Сохрани в локальном `agent-state.json` версии инструментов, модель/ускоритель, проверенную площадку, фактические ограничения и успешную команду без секретов. Не записывай успех для непроведённых строк.

## Если тест падает

Сначала `status`, затем `worker.log`, `capture.log` или `asr.log` и соответствующий `chunks/*.json`. Не удаляй аудио. Не удаляй lock-файлы и не завершай все процессы Chrome/Edge/GStreamer на компьютере. Для этой сессии используй `stop`; после проверки идентичности осиротевших процессов — `process`.

Ошибка ASR не должна останавливать запись. Ошибка самого захвата должна быть заметна и оставлять доступ к сохранённым данным. Если проблема воспроизводится, исправь минимальный участок и добавь тест; отдельно укажи, какая проверка требует реального Windows-устройства.
