# Личные профили

Создай профиль командой `auto-meets init --profile profiles/study.toml`.
Для работы можно создать второй: `auto-meets init --profile profiles/work.toml`.
Шаблон находится в `auto_meets/templates/profile.toml`.

TOML-файлы этой папки не попадают в Git. Источники календаря, личные пути и пожелания остаются на компьютере пользователя. Относительные пути считаются от файла профиля. По умолчанию оба профиля используют общий `../data`, чтобы запись не запускалась дважды.
